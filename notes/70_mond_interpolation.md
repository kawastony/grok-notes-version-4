# MOND interpolation stays free

**Date:** 2026-10-09
**Status:** Survey. Cone does not select a function.

Deep MOND fixes only the two ends: mu(x) to x when x is small, mu(x) to 1 when x is large, with x = g/a0. The join is free.

Standard: mu(x) = x / sqrt(1+x^2). Simple: mu(x) = x/(1+x). The n-family is mu(x) = x / (1+x^n)^(1/n). The SPARC RAR form is g_obs = g_bar / (1 - exp(-sqrt(g_bar/g0))). Simple and RAR transition more slowly than standard. Galaxy fits prefer the slower join. Solar-system tests want a faster return to Newton. No derivation in the notes picks one.

The kink packet remains the earned internal object: zero mode, split, transfer clock. It does not supply a0, the interpolation, or the frozen galactic exponent.
