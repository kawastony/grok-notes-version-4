# Parent dictionary

**Date:** 2026-10-05
**Status:** Symbolic only. No calibration number inserted.

## Parent

The lattice kink is the discretization of

H = -i hbar c sigma_y d/dx + m(x) c^2 sigma_z,

m(x) = m0 tanh(x/a) outside a wall, and m0 tanh((|x|-d a)/a) for two walls. The lattice hop -i sigma_y /(2 dx) matches this if the energy unit is E* = hbar c / a and the dimensionless v is m0 c^2 / E*.

Inherited, once a or m0 is supplied from outside:

xi_phys = a /(2v) = hbar c / (2 m0 c^2),

Delta E_phys = E* Delta E_lat,

t_phys = hbar T / E* = pi hbar / Delta E_phys.

The zero mode stays at zero. The transfer ledger is unchanged. This is the parent. It does not choose a or m0.

## Calibration not run

A one-point match would set E* or a from one external number and then predict the other rows. No such number is justified in the packet notes. The 18.7 eV line, the Paper-24 ruler, and z_t = 0.748 are not identifications of this split. They were not inserted. The dictionary stays symbolic.
