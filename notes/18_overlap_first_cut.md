# Overlap index, first cut

**Date:** 2026-10-02
**Status:** New operator class. The r=1 Wilson branch stays closed.

## Operator

Kernel is the Wilson-Dirac hedgehog on an open L=4 cube. The grading is a gamma5 that anticommutes with beta. The v2 grading, where gamma5 and beta commute, is not used. Index is half the trace of gamma5 sign(H). A kernel mode is not signed.

## Result

| v | index | kernel | min abs |
|---|-------|--------|---------|
| 0 | 0 | 0 | 0.854 |
| 1.5 | 0 | 0 | 0.022 |
| 2.5 | 0 | 0 | 0.144 |

No row equals N_def=1.

## Reading

This is not a rescue of the closed branch. It is the first overlap count, on a box too small and too open to be a continuum hedgehog at infinity. The index is defined, and it is zero. A larger overlap, or a domain-wall on a background whose topology the overlap can see, is still unbuilt. The Wilson finite-volume bridge stays closed.
